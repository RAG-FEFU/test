### Правила ветвления (v 0.0.1):
Используемые префиксы:
- feature
- fix
- test

feature - префикс для ветки с новыми фичами
fix - префикс для ветки с исправлениями ошибок
test - ветка для экспериментов, тестовые ветки для тестовых прогонов и тд

Правила именования:
- {префикс}/FEFU-RAG-{номер задачи}/{краткое-описание задачи}
